# Dhaka Holiday — Online Automated Money Receipt

This is the online-ready version of the Dhaka Holiday automated money receipt system.

## What it does
- Secure Supabase email/password admin login
- Online receipt database
- Atomic automatic receipt numbers (`DH-00001`, `DH-00002`, ...)
- Create/edit/search receipts
- Multiple particulars/items per receipt
- Automatic total and amount-in-words
- Payment mode selection
- Live receipt preview
- Print / Save as PDF from the browser
- Company settings stored online in Supabase
- Responsive dashboard

## Important
The ZIP is the complete application, but it is **not publicly deployed yet** because deployment requires access to your own GitHub/Cloudflare/Supabase accounts. Do not put a Supabase service-role key in the browser. Use only the anon/publishable key.

## 1. Create Supabase project
1. Open https://supabase.com and create a free project.
2. In SQL Editor, paste and run `supabase-schema.sql`.
3. In Authentication > Users, create the admin user with an email and password.
4. In Project Settings > API, copy the Project URL and the anon/publishable key.

## 2. Connect the app
Open `config.js` and replace the two placeholders:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

Do not use the service-role/secret key.

## 3. Put it online for free
Recommended: Cloudflare Pages.
1. Create a GitHub repository and upload all files in this folder.
2. In Cloudflare Dashboard, Pages > Create application > Connect to Git.
3. Select the repository.
4. For a plain static site, no build command is needed. Output directory: `/`.
5. Deploy.

You will receive a free `*.pages.dev` address. A custom `.com` domain is optional and is not required for the system to work.

## 4. How data works
After Supabase is connected, receipts and company settings are stored in Supabase online. They are not dependent on browser localStorage. An authenticated admin can log in from another computer/phone and see the same receipts.

## 5. Security
- RLS is enabled on both tables.
- Only authenticated users can read/write receipt data.
- Receipt numbering is generated by a PostgreSQL sequence through an authenticated RPC, preventing duplicate numbers during concurrent use.
- Never expose the Supabase service-role key in frontend code.

## 6. Free-plan note
Supabase and Cloudflare both have free tiers, but they have quotas/limits and Supabase free projects may pause after prolonged inactivity. For business-critical long-term use, keep periodic exports/backups and upgrade later if needed.
